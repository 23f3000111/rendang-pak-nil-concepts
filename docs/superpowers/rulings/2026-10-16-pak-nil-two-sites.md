# Decisions log: the two Rendang Pak Nil website concepts

Every decision taken on the client's behalf while building both concepts. Each line says what was decided, why, and what it costs if it turns out wrong.

## Rulings

- Setup: Ruling: no clarifying round; built straight from the request (two sites modelled on Kantan flagship and ABIN site A, content from rendangpaknil.com, Instagram and Facebook) — the request names both references and all sources, and the user pre-approved every step on the previous pitches — cost if wrong: direction changes after review.
- Setup: Ruling: Concept A = Kantan-structure flagship store "Citarasa Istana", Concept B = ABIN-structure playful site "Ingat Rendang, Ingat Pak Nil!" (the brand's own Instagram line) — order follows the user's message — cost if wrong: folder names.
- Setup: Ruling: no git repository or commits until asked — the system rules say commit only when asked; the folder is GitHub Pages ready (.nojekyll) — cost if wrong: one `git init` and push on request.
- Setup: User direction (17 Oct): publish on GitHub Pages. Pushed to the public repository 23f3000111/rendang-pak-nil-concepts (named like the earlier `*-concepts` repositories, public as they are) with Pages serving `main` from the root; `source-assets/` stays out through `.gitignore`.
- Content: Ruling: no halal certification claim anywhere — the packs carry "Produk Keluaran Muslim", BeSS and "Frozen Product" marks but no JAKIM logo; the FAQ and chat answer the halal question with exactly that — cost if wrong: one copy line once the client confirms a certificate.
- Content: Ruling: the chat assistant is "Tanya Dapur" (ask the kitchen), never "Pak Nil" — a bot speaking as a real celebrity would misrepresent him — cost if wrong: a rename.
- Content: Ruling: shop sizes and prices are the current site's (500 g / 1 kg); the new Warisan 480 g / 980 g packs appear as the new look from MIHAS 2026 (hero, a dedicated section, product galleries) without prices — their prices are not published — cost if wrong: swap product images and sizes once the new packs ship.
- Content: Ruling: A uses the Warisan × PakNil badge as its logo (the newest official mark); B uses a typeset "Rendang Pak Nil" wordmark (the current site's logo is plain text) with the badge in the footer — cost if wrong: logo swap.
- Content: Ruling: the agent programme has no published terms, so tiers/commission in A's portal and both agent forms are labelled sample data; the forms compose a WhatsApp message to +60 11-6982 5208 — cost if wrong: copy edits.
- Content: Ruling: WhatsApp orders and enquiries go to +60 11-6982 5208 (website footer, wa.me link and pack); the Instagram order line +60 11-6097 5809 and the Facebook number +60 13-707 0013 are listed as alternatives in the contact sections — cost if wrong: one data field.
- Assets: Ruling: Unsplash photos (Unsplash licence) only for dishes the client has not photographed (chicken rendang, sambal, satay with kuah kacang, ketupat) and the spice cut-outs; every one is listed in CREDITS — cost if wrong: swaps when the client sends photos.

- A: Ruling: headings use Fraunces (sentence case), echoing the serif on the new Warisan pouches, instead of Kantan's condensed caps; Anybody condensed caps (the current site's heading face) is kept for product names, prices and numbers, Hanken Grotesk (the current site's body face) for text — gives A its own voice while keeping Kantan's three-voice system — cost if wrong: token swap.

## Deferred minor issues

- Pack renders show the 1 kg label for every size; the client has no separate 500 g render. Swap when they send one.
- Some reel stills carry the reel's burned-in captions (for example "dan tahan lama"); swap for clean frames or photos when the client sends originals.
- In B's hero the spices fall behind Pak Nil and the packs (the canvas sits under the stage, as in ABIN), so a spice is sometimes pounded out of sight.
- The rendang scene's pack images are the same renders as the cards; dish photos per menu would make the scene richer once the client has them.
- Phone layouts were spot-checked at 390 px (no overflow, menus, cards and forms usable) but not polished; the user's priority is desktop.
